# Walder — where it stands and what's next (2026-11-18)

**Draft, not committed.** Where the open-items list should live is one of your decisions below.

Written by eight read-only sweeps from the first commit to 0.3.0, synthesised by Fable and fact-checked by a separate critic; the critic's corrections are folded in.

## In one minute

- **The app is in good shape and 0.3.0 is out.** It was published today with both installers, CI is green, GitHub has no open issues or pull requests, and the Mac checkout has one branch and nothing stashed.
- **The biggest gap is that 0.3.0 shipped ahead of its on-screen checks.** The new Walder window has no QA rows of its own, eleven rows that changed with it were never re-run, and nobody has installed the published 0.3.0 installers by hand.
- **Windows is the weakest side.** The Walder window has never been seen on a Windows screen. At 125 % scaling the dog drifts and the window grows while dragged; a fix was written on the PC and never applied.
- **Accessibility is promised in writing but untested.** No screen reader has been run against the Walder window on either platform, and the checklist has no screen-reader or keyboard rows.
- **Signing is still the gate for three things.** There is no Apple certificate, so Mac users still need "Open Anyway", and auto-update and Electron fuses wait on it. Windows has no signing plan at all.
- **The paperwork has drifted.** AGENTS.md sends every agent to a roadmap that finished in September, the build log stops at 0.2.8, and nine review files for Yuna sit uncommitted.
- **Top 3 next steps:**
  1. Verify what 0.3.0 already shipped, on both machines.
  2. Apply and test the 125 % Windows fix.
  3. Write one current open-items list and point AGENTS.md at it.
