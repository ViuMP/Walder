# Walder 0.2.0

The first release published to this repository. Walder 0.1.2 installs will start offering it from the tray.

## New
- **Tokens today** row per service on the hover card, counted from the CLIs' own transcripts on your machine (Claude Code and Codex). Since local midnight, includes cache reads, so it matches billing. Absent when a CLI is not installed.
- **Card size**: Large, Medium and Small (condensed) in the tray menu.
- **Real 7-day Fable row** from claude.ai's per-model limits. The shared-pool mirror is now only a fallback.
- **Extra usage** money row and **Codex credits** row.
- **Silver-dapple coat** and a new golden art set: still idle with blinks, approved worried and exhausted poses, clearer `out` pose, shared heart / question-mark / sleep glyphs.
- Hide-when-idle mode with a shortcut; `update` bubble kind.

## Fixed
- The hover card now appears over macOS full-screen apps.
- Only the specified usage windows reach the card. Unknown windows (for example "Amber ladder") are dropped.
- A second queued exhaustion alert is no longer discarded when the first is dismissed.
