# Walder 0.2.6

The release where Walder learns two more services and a second way to stand — or rather, to lie
down. Cursor and GitHub Copilot join Claude and ChatGPT on the hover card, read from the logins
you already have on the machine. The weekly pool, which the face has never shown, now has a
posture of its own. And a long list of smaller things from the codenotch gap analysis: bark
presets, an optional bark sound, a sessions block that says which terminal wants you, and a card
that no longer has headings over "not logged in".

## New

- **Cursor.** Read from the editor's own login (`state.vscdb`), never a browser sign-in — a
  cursor.com login would create an empty second account. Rows: `Cursor plan`, `Cursor Auto` when it
  differs from the plan figure, and `Cursor on-demand` when a spend limit exists. The plan resets at
  the billing cycle end.
- **GitHub Copilot.** Read through the GitHub CLI's token (`gh auth token`); Walder never logs in,
  refreshes or writes anything itself. Rows: `Copilot premium`, `Copilot chat`,
  `Copilot completions`, each a percentage of the month's quota with the account-wide reset date. An
  account with no Copilot at all says so instead of "endpoint changed".
- **He lies down for the weekly pool.** The face still follows Claude's 5-hour window. When either
  `7-day (all models)` or `7-day Fable` reaches 90 % he lies down with his head up, and from 95 %
  with his head on his paws — two held poses, no animation, so nothing moves while he rests. Barks,
  perks and the `?` play over the lie and he stays down. Nothing about this is new art you have to
  approve: the strips were approved in the gallery.
- **Barks ▸ Quiet / Normal / Chatty.** Quiet barks at 95 and 100 %, Normal is what he always did
  (80, 85, 90, 95, 100), Chatty every 10 %. Switching never repeats a level he has already announced.
- **Bark sound.** A tray checkbox, off by default. One short bark (a CC0 recording of a small dog)
  plays with a threshold bark and with nothing else — not with `Claude done`, not with a `?`.
- **SESSIONS on the Large card.** Which Claude Code or Codex sessions are live, in which folder, and
  whether each is working, waiting or done. Entries older than thirty minutes drop off.
- **Click the dog to bring the terminal forward.** While a `Claude waiting` is up, a pet raises the
  app that owns that session (Terminal, iTerm, VS Code, Cursor…). Claude Code only for now: Codex
  hooks carry no process id.
- **Reset times ▸ Clock time / Countdown**, and the rest of the P1 batch from 0.2.5's follow-up,
  are in this build too if you skipped it.

## Changed

- **A service you are not logged in to is not on the card.** No heading, no "not logged in" note;
  the Accounts submenu is where a login is offered. A login that exists and fails still shows, with
  what to do about it.
- **The Accounts submenu** lists all four services. Cursor and Copilot have no Log in / Log out
  items because their logins belong to the editor and to `gh`.
- **Every sentence Walder says comes from one table** (`src/core/strings.ts`). English only for
  now; a second language is a second table.
- **Developer ▸ Inject usage** gains `Weekly 92%` and `Weekly 96%`, one for each lying pose.

## Fixed

- The first bark sounded a beat after the bubble. The clip is now loaded the moment the setting
  turns on, and plays on the beat.
- A renderer reload while a bark was on screen could sound it twice.
- The `?` for a session that no longer exists stands down after thirty minutes (0.2.5's rule),
  and a `Claude done` no longer stands him up when he is lying down.

## Notes

- **Apple Silicon only**, unsigned, as before: **System Settings ▸ Privacy & Security ▸ Open
  Anyway**, then **Done**. The README has the four steps.
- **Gemini is not coming in this form.** Google closed the personal Gemini CLI sign-in in favour of
  Antigravity, and the consumer Gemini app has no usage endpoint. Walder does not read Gemini.
- Cursor and Copilot are read at the same 180-second cadence as the others, with the same backoff,
  and nothing about either account is logged — key names only, never numbers, never a token.
- If you run several services, `Primary service` in the tray decides whose rows sort first; the face
  is Claude's 5-hour window whatever you pick.
