# Walder 0.2.7

The release after a day with 0.2.6 installed. Everything in it comes from what the installed app
did on Victor's Mac that the dev build had not: four phantom ChatGPT rows, a Copilot section that
said "no Copilot" because a Finder-launched app cannot see `gh`, a `Codex waiting` that popped up
while Codex was working, and `done` bubbles that stayed after the reply had been read. And one
addition: Gemini, read the way Antigravity itself reads it.

## New

- **Gemini.** While Antigravity is running, Walder asks its local language server over loopback for
  the same figures Antigravity's own panel shows: `Gemini weekly` and `Claude & GPT weekly` (more
  windows on plans that have them). Nothing is sent to Google, there is no login window, and the
  section says "open Antigravity" when it is not running. This is the route codenotch found: Google's
  own quota call refuses every client that is not Antigravity.
- **Show in overview is one checkbox per service.** Claude, ChatGPT, Cursor, Copilot, Gemini. An
  unticked service loses its section and its barks. If you had hidden every row of a service in
  0.2.6, it stays hidden until you tick it.
- **Developer ▸ Inject usage ▸ Weekly 92% and Weekly 96%**, one per lying pose.

## Changed

- **A `?` or a `done` is held for three seconds before it shows.** If the same tool contradicts it
  inside that window — you type, the turn ends, or a command you approved finishes running — it is
  dropped and you never see it. This is what stops a Codex approval check that never asked you
  anything from putting a `?` up mid-turn, and what stops a batch of agents finishing from queueing a
  `done` each. A real approval prompt waits for you and cannot be answered in three seconds, so it
  shows exactly as before.
- **The `done` goes away when you come back.** Typing your next prompt clears that tool's `done`;
  bringing the tool's own app to the front clears its `done` and its `?` (Claude Code only — Codex
  sessions carry no process id).
- **The hooks files carry a fourth entry, `PostToolUse`.** Reinstall both from the tray after
  updating (Tray ▸ Install Claude Code hooks…, Install Codex hooks…); Codex asks you to trust the new
  entry once via `/hooks`.
- **He faces the centre of the main display** from wherever he stands, on any monitor.
- **A service you are not logged in to is not on the card** (already in 0.2.6's follow-ups; stated
  here because the first 0.2.6 dmg predates it).

## Fixed

- **Four rows named `ChatGPT 0…3` with `?`.** A fallback ChatGPT endpoint answered with a list of
  model presets and the parser turned them into windows with no number. A row now needs a number,
  and a path that yields none is skipped for the next one.
- **"No Copilot yet" in the installed app.** `gh` is now looked for on PATH and in `/opt/homebrew/bin`,
  `/usr/local/bin`, `~/.local/bin` and `/usr/bin`, the way the Claude renewer finds `claude`.
- A quit or restarted Antigravity is noticed within the same poll, not one poll later.

## Notes

- **Apple Silicon only**, unsigned: **System Settings ▸ Privacy & Security ▸ Open Anyway**, then
  **Done**.
- What Walder reads for Gemini: the running Antigravity language server's process id, its listening
  ports and its CSRF argument, all on this Mac, nothing else from the process table; the token is
  never logged. `docs/privacy.md` has the row.
- Installers are now built only for release tags and manual runs; every pull request still gets the
  type-check and the tests.
